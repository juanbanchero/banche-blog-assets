# banche-blog-assets

Assets estáticos para [banche.bearblog.dev](https://banche.bearblog.dev).

Servidos vía jsDelivr CDN. Ejemplo:
`https://cdn.jsdelivr.net/gh/juanbanchero/banche-blog-assets@main/banche-favicon.svg`

## Contenido

- `banche-favicon.svg` — fuente vectorial (Catppuccin Mocha base + lavender)
- `banche-favicon-{16,32,48,64,128,180,192,512}.png` — tamaños raster
- `banche-favicon.ico` — multi-res 16/32/48 (legacy browsers)
